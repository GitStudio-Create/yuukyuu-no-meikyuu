# 悠久の迷宮

外部ライブラリを使わない、オリジナルの軽量ターン制ローグライクです。

起動後はプッシュスタートから3つの「冒険の書」を選び、王城で物語を進めて迷宮へ出発します。冒険の書ごとにストーリーと迷宮途中の状態を保存できます。

Stage 18では、矢・投げ物・杖・通常攻撃の結果を、対象名と実際のHP差分に基づくダメージ、状態変化、撃破、外れ・床落下まで戦闘ログへ表示します。

Stage 19では、歩行中の余計な上下揺れを除き、8方向の向き矢印と、起床した敵がその敵ターンには攻撃しないルールを追加しています。

Stage 20では、1マス移動の整数ピクセル補間、道標の紙片による地形・道具・階段・罠の全表示（敵は視界内のみ）、睡眠敵の起床ターン固定を実装しています。

Stage 21では、プレイヤーとカメラを同じ補間率で描画し、BGMを一時停止して約2.15秒のWeb Audioファンファーレを鳴らすレベルアップ演出を追加しています。

Stage 22では、敵の移動補間・攻撃・被弾・消滅演出、全攻撃手段共通の経験値報酬、敵別のドロップ率とカテゴリを追加しています。

Stage 23では、攻撃草の実ダメージログ、投射物着弾後の消滅順序、プレイヤー死亡演出後のゲームオーバー表示、専用曲と終了選択肢を追加しています。

Stage 24では、矢のみ99本まで自動合算し、投射物アニメーション完了後に命中処理と敵ターンを実行する行動キューを追加しています。

Stage 25では、投射物・投げ物・攻撃杖・攻撃草の命中で睡眠を解除し、近接した外れ音でも50%で起床する共通ルールを追加しています。

Stage 26では、敵ターン入口で起床済み個体の行動力を破棄し、10件スクロールログと、道写し使用時の通常画面・ミニマップ別敵表示を追加しています。

Stage 27では、壁衝突した投げ物の安全な周辺落下と、睡眠中の敵本体を静止フレームに固定する描画制御を追加しています。

## 遊び方

- 矢印キー / WASD / 画面の方向ボタンで移動
- 敵のいる方向へ移動すると通常攻撃
- 青白い階段に乗ると次の階へ進む
- 拾った道具は道具袋をタップ（PCでは数字キー 1〜6）して使用
- Spaceまたは攻撃ボタンで通常攻撃。同じ部屋内にいる相手だけ斜め攻撃可能
- Zまたは足踏みボタンで、1ターン待機して自然回復
- Shift＋方向、または向き変更を押しながら方向ボタンで方向転換
- Ctrl＋縦横2方向、または斜め移動モードで斜め移動を補助
- Xまたはステータスボタンで詳細表示
- 道具袋のアイテムを選び、カテゴリ別メニューから使用・装備・投擲・設置
- Iキーで道具袋を選択し、矢印・Enter・Escだけでも詳細確認から実行まで操作
- B＋方向、または走るボタンを押しながら方向入力で直線移動
- 階段上では「下りる」を選ぶまで現在階に留まる
- Fキーまたは矢撃ちボタンで装備中の矢を発射
- 矢・杖・投げる操作は斜め方向にも使用可能
- Gキーまたは床コマンドの「拾う」で足元の道具を拾う
- 道具袋に空きがある場合、床の道具は移動時に自動取得
- Qキーまたは「中断」で確認後に現在の冒険を保存し、冒険の書選択へ戻る
- 見えている敵はPCではマウスホバー、スマホでは敵をタップして情報確認
- 冒険の状態はブラウザの `localStorage` に自動保存

## セーブについて

- 冒険の書は1～3の3枠です。
- セーブにはブラウザの `localStorage` を使用します。
- ブラウザの閲覧データを削除すると、冒険の書も消えます。
- シークレット／プライベートモードでは、終了後に保存が残らない場合があります。
- セーブは使用中の端末とブラウザ内だけにあり、別端末とは共有されません。

`index.html` を開くだけで遊べます。静的ファイルのみなので GitHub Pages にそのまま配置できます。

## GitHubでの管理メモ

- ゲーム名は「悠久の迷宮」です。
- 基本構成は `index.html`、`style.css`、`js/`、`tests/`、各種ドキュメントで管理します。
- 開発時は `AGENTS.md` のルールに従い、依頼範囲外の仕様変更や長時間テストは行わない方針です。
- `BGM/` 配下のMP3音源は、配布元とライセンスを確認済みの素材としてプロジェクトに含めます。
